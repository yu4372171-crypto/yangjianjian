# 当前源码版本边界

羊剪剪的公开源码可以启动桌面应用、登录、创建项目、读取本地视频、调用智能剪辑与时间线引擎，并完成字幕、配乐、画面处理、任务记录等本地工作流。

公开仓库同时保留了已安装版本中的 Web UI 构建产物。由于原始 Vue 工程没有保留，仓库不声称这些构建文件是未压缩的原始前端工程。部分云端生成、配音、文案批量生成和第三方素材页面要在设置中配置相应模型或服务后才能使用；界面会给出缺失服务或模型的原因。

以下内容不随 Git 发布：

- AI 模型权重和模型缓存
- FFmpeg/FFprobe 二进制
- Windows 安装包和运行时目录
- 应用更新私钥及签名凭据
- 顾客项目、视频、成片、日志、数据库和 API 密钥

开发环境验收覆盖本地账号、项目、素材索引、编辑器状态、视频探测、时间线静态资源、任务 sidecar 启停和桌面构建。正式发布候选版本仍应在目标 Windows 机器上执行一次真实模型、真实素材和导出成片的端到端验收。
